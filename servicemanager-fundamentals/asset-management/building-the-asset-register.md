# Building the Asset Register

## Multiple ways to populate your asset register

Assets can be added manually, uploaded in bulk from a CSV file, or synchronized automatically from external sources using Hornbill's Asset Import utility, which connects to common discovery and inventory tools including Microsoft SCCM, Microsoft Intune, Certero, Lansweeper, JAMF, Google Workspace, and VMware Workspace ONE - covering both hardware discovery and software inventory (including installed software detected on managed devices). Assets can also be linked to and updated from related records such as requests, keeping the register current as work happens.
