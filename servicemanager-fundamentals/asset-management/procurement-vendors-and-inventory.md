# Procurement, Vendors, and Inventory

## Connecting assets to procurement and vendor information

Asset records include fields for order number, order date, invoice number, and a linked supplier, and can be connected to Hornbill Supplier Management for fuller vendor and contract detail, including leases and warranties. Assets can also be linked to the projects that delivered them, giving a complete thread from procurement through to the asset in daily use.

**Learn more:** [Asset Structure](/servicemanager-user-guide/asset-management/asset-structure) | [Hornbill Supplier Management](https://www.hornbill.com/products/supplier-management)

## Maintaining inventory levels

Inventory can be maintained through both automated imports and manual updates, and asset counts by type and status are visible through the Asset Dashboard and reportable through Hornbill's reporting tools. Hornbill does not provide a dedicated, out-of-the-box low-stock reorder trigger; where this is required, it's typically achieved by building a threshold-based report or view and using workflow automation to raise a purchase request when it's breached. Worth confirming the current state of play with your Hornbill contact if automatic reordering is a firm requirement.

**Learn more:** [Assets Overview](/servicemanager-user-guide/asset-management/overview)

## Standard, pre-approved assets in your catalog

Because request catalog items can be configured to pre-populate specific asset types and details, administrators can offer a defined set of pre-approved, standard assets through the service catalog - separate from the wider portfolio of all supported asset types - giving users a curated set of choices when they raise a request.

**Learn more:** [Using Workflows with Service Manager](/servicemanager-config/customize/workflows/using-workflows-with-service-manager)

## Linking consumable assets to the service catalog

Assets and asset types can be linked directly to requests raised through the service catalog, whether an agent is linking a specific asset a user already has or a type of asset being requested. Workflow automation can then update the linked asset's status, ownership, or other attributes automatically as the request progresses.

**Learn more:** [Assets Action](/servicemanager-user-guide/service-portfolio/requests/asset-action) | [Requests Automation](/servicemanager-config/customize/workflows/requests-automation)
