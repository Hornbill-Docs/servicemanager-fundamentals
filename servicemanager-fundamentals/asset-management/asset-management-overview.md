# IT asset management fundamentals

IT assets are a vital part of your service desk. You raise incidents against assets, plan changes around them, and use a large portion of your IT budget to maintain them. This guide helps you use the core capabilities of Hornbill Service Manager to manage your IT assets. We will walk you through the process of building an asset register and managing assets until their end-of-life disposal.

We provide a plain-language explanation for each capability. You will also find links to technical guides that help your teams configure and use these features.

## Before you begin

Before you start managing your assets, ensure you have the correct permissions to access the following resources:

* The Hornbill Service Manager application.
* The Service Manager Configuration Guide for administrative tasks.
* The Service Manager User Guide for daily operations.

### Steps to use this guide

1. **Review the asset management capabilities**
    Read the summary for each IT asset management capability to understand how Hornbill supports your business goals.

2. **Identify your technical requirements**
    Determine if you need to set up the system or perform daily tasks.
    * If you are an administrator who needs to tailor the application, use the [Service Manager Configuration Guide](/servicemanager-config/index).
    * If you are a service desk agent or an end user performing daily tasks, use the [Service Manager User Guide](/servicemanager-user-guide/index).

3. **Access the detailed documentation**
    Select the links provided in each section to open the relevant technical documentation. These guides provide the specific steps your technical teams need to follow.

### Expected result

You will have a clear understanding of how Hornbill Service Manager handles IT assets. You will also have access to the specific configuration and user instructions required to manage your asset lifecycle.
